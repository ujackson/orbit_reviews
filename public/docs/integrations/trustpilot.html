Connect Trustpilot

Trustpilot public review import can use an API key and Business Unit ID. Private reviews and replies require Business-user OAuth access.

What you need

  • Trustpilot API access for your business account.
  • Your Business Unit ID.
  • A Trustpilot API key or OAuth access depending on the review features enabled.

Security

API tokens are encrypted at rest. Use a least-privilege token and rotate it if access changes.
